# AgentEcon — Economic Intelligence for AI Agents

x402-powered economic data API. Pay per query in USDC on Base mainnet.

## MCP Endpoint
```
https://econ.memoryapi.org/mcp
```

## Tools
- `get_inflation` — CPI inflation data (BLS)
- `get_jobs` — Labor market data (BLS)
- `get_macro` — GDP, Fed rates, Treasury yields (FRED)
- `get_energy` — WTI crude, natural gas, gasoline (EIA)
